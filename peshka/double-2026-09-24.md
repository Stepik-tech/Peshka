## Задание 1 (баг-фикс): Карточка спортсмена перепутана: рост и вес подставлены не в свои строки. Должно быть: Рост: 1.82 м В

```java
public class Athlete {
    public static void main(String[] args) {
        // ТЗ: карточка спортсмена:
        // Рост: 1.82 м
        // Вес: 76 кг
        double height = 1.82;
        int weight = 76;
        System.out.println("Рост: " + height + " м");
        System.out.println("Вес: " + weight + " кг");
    }
}
```

## Задание 2: Карточка товара для магазина. Данные хранятся в переменных. Выведи ровно три строки: Товар: Чайник Ц

```java
public class Product {

String a = "Чайник";
double b = 1499.99;

    }

```

## Задание 3: Метеостанция: утренняя температура 18.5, дневная 24.0. Храни обе в double-переменных, посчитай средн

```java
public class WeatherAvg {
    public static void main(String[] args) {
        // ТЗ: утро 18.5, день 24.0 (double). Посчитай среднюю и выведи:
        // Утро: 18.5
        // День: 24.0
        // Средняя: 21.25   ← (утро + день) / 2
double ytro = 18.5;
double den = 24;
double result = (den + ytro)/2;
System.out.println("Утро: " + ytro);
System.out.println("День: " + den);
System.out.println("Средняя: " + result);
    }
}
```
