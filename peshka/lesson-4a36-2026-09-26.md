## Задание 1 (баг-фикс): Чек кафе считает неверно. Хлеб стоит 35 руб., молоко 89 руб., чек должен показать: Сумма: 124 А прог

```java
public class Receipt {
    public static void main(String[] args) {
        // ТЗ: хлеб 35 руб. + молоко 89 руб. → Сумма: 124
        System.out.println("Сумма: " + (35 + 89));
    }
}
```

## Задание 2: Поход за продуктами: хлеб 35 руб., молоко 89 руб. Выведи три строки: Хлеб: 35 руб. Молоко: 89 руб. И

```java
public class Shopping {
    public static void main(String[] args) {
        // ТЗ: хлеб 35 руб., молоко 89 руб. Выведи:
        // Хлеб: 35 руб.
        // Молоко: 89 руб.
        // Итого: 124 руб.   ← посчитай сложением (35 + 89)
    
int xleb = 35;
int moloko = 89;
System.out.println ("Хлеб: " + xleb + " руб.");
System.out.println ("Молоко: " + moloko + " руб.");
System.out.println ("Итого: " + (35 + 89) + " руб.");
    }
}
```

## Задание 3 (баг-фикс): Экскурсия для класса: 2 взрослых и 3 ребёнка, билет стоит 400 руб. ТЗ в консоли: Всего: 2000 А прогр

```java
public class Trip {

```

## Задание 4: Велосипедный заезд: 3 этапа по 12 км, плюс 5 км дороги до старта. Выведи ровно три строки: Этапы: 36

```java
public class Race {
    public static void main(String[] args) {
        // ТЗ: 3 этапа по 12 км + 5 км до старта. Выведи:
        // Этапы: 36 км        ← считай: 3 * 12
        // Дорога до старта: 5 км
        // Всего: 41 км       ← считай: (3 * 12 + 5)
System.out.println ("Этапы: " + 36 + " км");
System.out.println ("Дорога до старта: " + 5 + " км");
System.out.println ("Всего: " + (3*12+5) + " км");
    }
}
```
