### 📌 Задание 1 · найди и исправь баг

<details>
<summary>Условие</summary>

> Меню столовой слиплось в одну строку. Программа должна вывести ровно три строки: МЕНЮ Суп — 45 руб. Компот — 20 руб. А сейчас все три строки печатаются одной линией. Найди и исправь баг.

</details>

```java
public class Canteen {
    public static void main(String[] args) {
        System.out.println("МЕНЮ");
        System.out.println("Суп — 45 руб.");
        System.out.println("Компот — 20 руб.");
    }
}
```

### 📌 Задание 4 · напиши программу

<details>
<summary>Условие</summary>

> Визитка школы для дневника печатается на экран. Программа должна вывести ровно пять строк — с пустой строкой-разделителем после заголовка: ШКОЛА № 15 Уроки: 08:00 — 14:00 Кружки: 15:00 — 18:00 Секции: до 20:00 Пустая строка после заголовка — полноценная строка вывода: для неё нужна своя команда.

</details>

```java
public class Price {
    public static void main(String[] args) {
System.out.println("ШКОЛА № 15");
System.out.println("");
System.out.println("Уроки: 08:00 — 14:00");
System.out.println("Кружки: 15:00 — 18:00");
System.out.println("Секции: до 20:00");
}
}
```
